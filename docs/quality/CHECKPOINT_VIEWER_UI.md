# Project viewer interface — 2026-11-08

Authenticated `viewer` accounts now see a read-only, membership-filtered project summary list instead of an admin workspace. The list returns at most 100 summaries and visibly says so; there is no detail beyond project name, client label and status. Refresh re-queries current membership; a revoked project's previously rendered summary remains on screen until refresh, while all new server requests are denied immediately. Sign-out revokes the session. Other business endpoints remain admin-only, and grants still require direct admin API calls: no membership administration UI yet.
